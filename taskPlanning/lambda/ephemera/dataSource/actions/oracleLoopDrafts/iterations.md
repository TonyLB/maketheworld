# Oracle drafts: problems, proposals and what was tried

Owned by the [oracle loop plan](../AGENT.oracleLoop.planning.md), like the drafts beside it, so it carries across episodes of oracle tuning. An episode's plan (the first, oracle drafts, retired 2026-11-10 at its exit (c)) pulls from the library and writes to the ledger. A trial of this shape for exploratory steps (2026-11-09; the user's proposal, the forms mine).

- **Problems** say what is wrong, where it shows, and what "solved" means. A problem is solved when its cases give the right end result and the guards still do. A draft that turns up a new problem adds a row.
- **Library** entries are one change each, so one entry is one draft (or, for a probe, one batch that changes no prompt). Add ideas freely, with their source; don't argue an entry before trying it.
- **Slice 4's exit (c), 2026-11-10:** the episode ended with the oracle decomposing into pieces that each make one judgment per call. Every row below keeps its last status as history, and the [disposition](#disposition-at-slice-4s-exit-2026-11-10) at the end says where each open one goes.
- **Ledger:** one line per batch. The detail is in the draft's `.notes.md`. A finding about one of the oracle loop plan's guesses also goes to its [seam ledger](../AGENT.oracleLoop.planning.md#seam-ledger).
