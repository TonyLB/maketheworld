## `transactWrite` and its transaction-request kinds

- [`mixins/transact.ts`](mixins/transact.ts) --- `withTransaction`'s `_transactionRequestItemToTransactWriteItems` method converts a single `TransactionRequest` item into `{ items, successCallbacks, deleteCallbacks }`; `transactWrite` batch-fetches un-primed `Update`/`MultiKeyUpdate` keys in one `getItems` call, calls the conversion method per top-level item via `.flatMap(...)`, merges the callback arrays, and sends exactly one `TransactWriteItemsCommand`.
  - `TransactionRequest` union (`Put`, `Delete`, `Update`, `PrimitiveUpdate`, `SetOperation`, `ConditionCheck`, `MultiKeyUpdate`) is defined at the top of the file.
  - The `MultiKeyUpdate` branch (inside `_transactionRequestItemToTransactWriteItems`) builds a `priorRecord`/`nextRecord` pair via `produce`, then per key: `deepEqual` unchanged -> `_unchangedFieldConditions` -> `ConditionCheck`; changed -> `_optimisticUpdateFactory` (reused from `update.ts`, unmodified) -> `Update`. If a `cascade` is present, it runs after the reducer/diff step, and each returned item is converted **recursively** via the same `_transactionRequestItemToTransactWriteItems` method (after the `Update`-needs-`priorFetch` / no-nested-`MultiKeyUpdate` guards) and merged in.
  - `_marshalledKeyString` and `_unchangedFieldConditions` are private helper methods on `TransactionDBHandler`, both defined just above `_transactionRequestItemToTransactWriteItems`.
- [`mixins/update.ts`](mixins/update.ts) --- `updateByReducer` and `_optimisticUpdateFactory`: the single-item optimistic-lock-by-reducer machinery that `MultiKeyUpdate`'s "changed" path reuses directly. `UpdateExtendedProps` is the single-item `Update` kind's full prop surface (not shared by `MultiKeyUpdate`, which has its own smaller prop type, `TransactionRequestMultiKeyUpdate`, in `transact.ts`). `deleteCascade` (`update.ts:192-195`) is the precedent `MultiKeyUpdate`'s `cascade` field generalizes.
- Tests: [`mixins/transact.test.ts`](mixins/transact.test.ts) (the other 6 kinds), [`mixins/transact.multiKeyUpdate.test.ts`](mixins/transact.multiKeyUpdate.test.ts) (`MultiKeyUpdate`, including its `cascade` in a nested `describe`), [`mixins/update.test.ts`](mixins/update.test.ts) (single-item `Update`/`optimisticUpdate`).
